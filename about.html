About Page

Simple profile and project background

This page introduces the creator behind the project and explains the educational purpose of Bandung Hiking Trails Explorer.

Profile

My name is Rakhmat Senoaji. I created this website as part of the MAPID WebGIS Bootcamp assignment to practice building a simple tourism-themed website using plain HTML and CSS.

Education

I am currently learning web development and geographic information systems through the bootcamp. This assignment helps me understand how page structure and CSS styling work together.

Background

Bandung has many attractive outdoor destinations, and hiking trails are one of the tourism experiences that can be supported by clear route information. This project is a beginner-friendly concept for presenting those details online.

Learning Goal

Why this assignment was created

The main goal of this project is to practice semantic page structure using a navbar, main content, and footer while also applying CSS to create a cleaner and more modern appearance.

In the future, this concept could be expanded into a real WebGIS page that displays hiking routes, trail points, and accessibility information on an interactive map.
